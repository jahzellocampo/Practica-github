# Practica-github
"Ejercicio introductorio al uso de github"
Autor: Jahzell Lourdes Ocampo
Carrera: Ingeniería en sistemas, I año
proposito: Aprender a manejar respositorios, ramas y pull request
objetivo: Aplicar el flujo básico de trabajo con GitHub mediante la creación de un repositorio académico, el uso de
commits claros, la organización de archivos, la creación de una rama y la apertura o fusión de un Pull Request.
